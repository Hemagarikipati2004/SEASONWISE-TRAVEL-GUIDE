# SeasonWise – Seasonal Travel Recommendation System

SeasonWise is a web-based travel recommendation application developed using Python and Flask. It helps users explore travel destinations based on seasonal suitability and access weather forecast information.

## Features
- Seasonal travel recommendations using predefined rules.
- Weather forecast integration using the Open-Meteo API.
- AI chatbot integration for travel-related assistance.
- Destination information and travel discovery.
- User-friendly web interface.

## Technologies Used
- Python
- Flask
- HTML and CSS
- Open-Meteo Weather API
- Anthropic API for chatbot integration
- JSON for destination data

## Project Objective
The goal of SeasonWise is to make travel discovery easier by combining seasonal destination recommendations, weather information, and AI-assisted travel guidance.

## Current Status
This project currently uses rule-based recommendations and external APIs. An independently trained Machine Learning model is not yet implemented.

## Future Enhancements
- Develop an ML-based destination recommendation model.
- Train and evaluate a model using a suitable dataset.
- Personalize recommendations using user preferences and weather features.
